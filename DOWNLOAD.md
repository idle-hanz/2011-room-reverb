# Download / reconstruct the pack

1. Clone or download this repository.
2. Open the `dist/` folder.
3. Run the decoder for your OS:
   - **Windows:** `.\decode.ps1` (PowerShell)
   - **macOS / Linux:** `bash decode.sh`
4. That writes `2011-room-reverb.zip` containing the full software and docs.

See `dist/DECODE.md` for unzip / launch steps after decode.
