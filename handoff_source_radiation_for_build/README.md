# Source radiation for the 2011 Room Reverb: research, fits, design, handoff

This package covers source **directivity, orientation and apparent size** for the rebuild. It contains research with citations, a parametric source model fitted to open measured data (the "source fitter", mirroring the mic fitter), an offline prototype on the live early-field code with an omni null test, CPU benchmarks, UI mockups, and build briefs.

**Status:** research/design complete. Nothing was written into `software\` (read-only). The default = omni = bit-exact null.
