# GROK BUILD BRIEF: Source UI (Source desk + facing on Floor)

**Style:** modern and world-class, like Idle's other web tools (not Reaktor panels).
- Each tab is uncluttered and shows only the relevant controls.
- Drag-to-place on the floor plan and side elevation; the 3D view is orbit-only.
- Structure jargon goes under **Advanced**.
- Drag targets are clear, and controls sit next to the plots they affect.

**Mockups** (clearly MOCKUPS; the shapes are drawn from real fitted presets):
- `mockups/mockup_source_desk.png` (+ `.html`)
- `mockups/mockup_floor_facing.png` (+ `.html`)
- They are generated by `mockups/make_mockups.py`.

## 1. Where things live
| Place | What is added |
|---|---|
| **Floor · Side · 3D** tab (existing, `room_editor.js`) | On each source dot: a **facing handle** (a small hollow ring at the end of a short arrow, 30 px) and a faint **2 kHz radiation cut** under the dot. There is also a dashed **size circle** (radius a to scale; minimum 4 px). The side view gets a pitch handle. In 3D, a small cone/arrow shows the facing (orbit only; no dragging in 3D). |
| **Source** tab (new, between Floor and Mic; analogous to the Mic desk) | The full desk: source list, preset, yaw/pitch/size, radiation polar + balloon at selectable frequencies, and a "what the room hears" readout. |
| **Paths** tab (existing) | Hovering an image shows its emission angle (az/el in the source frame) and the radiation gain at 1k/4k. Optionally, image dots can be tinted by radiation gain. |
| **Mix** tab | Nothing by default. The `level_ref` make-up readout only (no new faders). |

## 2. Source desk layout (see mockup)

**Left column: "Sources in this room"**
- Chips list one chip per source. This track's source is highlighted, and linked Studio One instances appear in their own colour. "+ Link track" is a placeholder for the linked track-FX idea.
- **Radiation** dropdown, grouped as Voice · Brass · Strings · Woodwinds · Guitar amps & cabs · Keys · Reference. Each entry shows a tag badge (`measured fit` green / `assumed` amber) and the hold-out RMSE in its tooltip.
- **Yaw**, **Pitch** and **Size** sliders with numeric fields. Size shows the beaming onset "≈ c/2πa = 900 Hz" under it.
- Quick chips:
  - **Face mic**: yaw/pitch toward the mic centre (`yaw_to_face`).
  - **Face away**.
  - **Omni (bypass)**: this also greys out all radiation visuals.
- **Advanced ▸** (collapsed): aim offset az/el (read-only from preset, editable when unlocked), Level reference (On-axis / Power-matched), Tail follow α (0), Size jitter (off), Emission points M (1), Up/down asymmetry.

**Middle column: "Place & face"**
- **Top view** (to scale). The source dot is draggable to move it (same as the Floor tab); the ring handle drags yaw. Shift snaps to 15°, and double-clicking the handle faces the mic.
  - Overlays: the radiation cut at the **selected frequency** (filled) and at 500 Hz (dashed), scaled to 0/−10/−20/−30 dB. There is also a dashed line to the mic and an "N° off mic" label.
- **Side view** (length × height). The dot drags x/height, and the ring handle drags pitch.

**Right column**
- **Radiation card:**
  - frequency chips 250 · 500 · 1k · 2k · 4k · 8k;
  - a plane toggle: Horizontal / Vertical;
  - a **polar** with 4 frequencies overlaid (colour-coded) and the selected one bold;
  - a **3D balloon** (orbit only, WebGL or canvas wireframe) at the selected frequency, with the facing arrow.
- **"What the room hears" card** (live text, computed by `/api/source_preview`):
  - direct-to-mic C gain at the selected frequency;
  - the diffuse (tail) shelf, e.g. "−15 dB above 2.2 kHz: does not change with yaw";
  - make-up when `level_ref=power`.

## 3. Interaction spec
| Gesture | Target | Result | Feedback |
|---|---|---|---|
| Drag the dot | source dot (Floor, Source top/side) | move (as today) | position readout; the lobe follows |
| Drag the ring handle | hollow ring 30 px from the dot | yaw (top) / pitch (side) | the arrow rotates, and a live "yaw 20° off mic" label appears |
| Shift + drag the handle | — | snap to 15° | tick marks at 15° |
| Double-click the handle | — | face mic | 150 ms animated turn |
| Alt + drag the dot edge | the size circle | size radius | the circle grows; an onset Hz tooltip |
| Wheel over the handle | — | yaw ±5° | — |
| Hover the source | — | tooltip: preset, yaw/pitch, DI @ 2 kHz, tag | — |
| Keyboard (focused source) | ← → yaw ±5°, ↑ ↓ pitch ±5°, F face mic, O omni | — | the aria-live readout updates |
| Preset change | dropdown | coefficient push via `/api/live_params` (debounced 30 ms, like `pushLiveParams`) | the polar/balloon morph over 150 ms |

**Rules:**
- **Omni** hides the handle and lobe. The dot looks exactly like today, so there is no visual noise for the default.
- The drag target sizes are ≥ 16 px hit radius. The handle ring is visually distinct from the move dot (hollow vs filled), and the cursor is `grab` on the dot and a rotate cursor on the handle.
- **Linked instances:**
  - Another track's source is shown in its colour and is **read-only** from this instance. Clicking it offers "Open that track's instance".
  - An Advanced toggle, "Edit all sources here", allows editing them from this instance.
  - Each linked instance = one source with its own position, orientation and preset in the shared room.
- **Play/Render:** the same state feeds both. While Play runs, drags push params at ≤ 30 Hz. The C side ramps the coefficients over one block.
- **Performance of visuals:**
  - Polar and balloon data come from `/api/source_preview` (cached per preset × size) and are rotated client-side for yaw/pitch, so there are no server calls while rotating.
  - The Floor lobe is one 120-point path per source.

## 4. Visual language
- Source colour: amber `#ffb347` (this track), with other tracks in their own hues. Mic: mint `#7ee0c3` (matches the existing mic dots).
- Frequency colours: 250 blue · 1k light blue · 4k amber · 8k red, consistent everywhere (Source desk, Paths tint, Colour tab).
- Badges: `measured fit` (mint outline) and `assumed` (amber outline). The provenance popover shows the dataset, licence and RMSE.
