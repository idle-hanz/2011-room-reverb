## Package summaries

### 1. IIR colour verification (`1_iir_colour_verification/`)

- **Tables:** Build's 20 SOS tables are identical to the 27 Sep prototype.
- **Accuracy:**
  - 48 kHz: within **0.46 dB** of the fitter model for all 20 mics and angles (AT-C1 PASS).
  - 44.1 kHz: **fails AT-C4 for 2 omnis** (U87 Omni 0.69 dB, NT2A Omni 0.62 dB, at 180° around 15 kHz).
  - 88.2/96 kHz: up to 2.1 dB. The 48k parameters are reused at every rate.
- **Vs MEASURED data:** SOS adds ≤ about 0.1 dB to the fitter's own error.
- **Stability:** all poles stable (worst radius 0.99893).
- **HPF low end:** with the manufacturer HPF on, **the old FIR's 15–26 dB miss below 100 Hz is fixed** (SOS ≤ 0.19 dB).
- **Play:**
  - SOS and FIR null to −53…−61 dB where the FIR was right.
  - SOS roughly halves colour CPU: 1 source 0.63 vs 1.23 ms/block; colour costs +0.095 ms.
  - Play (C) and Render (Python) SOS agree within 1e-7 dB.
- **Bugs:**
  - (a) Two sources placed apart need 90 colour entries, more than MAX_IRS 64. Play colour silently switches off (this was already true on 27 Sep). Details at `live_stereo.c:55`, `fdn_worklet.js:158`, `live_bank.py:22`.
  - (b) Render uses a per-sample Python SOS loop (`sos_fit.py:123-142`), which makes Render 1.6× slower than FIR. `scipy.sosfilt` is bit-identical and 100× faster.
  - (c) Minor: no preset-hash check, no table builder, a docstring mismatch, silent truncation of k > MAX_SOS.
  - K11 (colour silently off on a rate mismatch) is unchanged.

### 2. K1–K4 (`2_known_issues_K1_K4/`): all four LOCKED 28 Sep; the findings below are historical

**All four are CONFIRMED with scripts.**

- **K1:** every coincident/near-coincident stereo preset (xy, ortf, nos, din, ms) aims its capsules inward.
  - Source 2 m left: L gain 0.54 vs R 0.96. Early L−R −4.8 dB and direct (with colour) −5.4 dB, while L arrives 12 samples first.
  - Negating the yaws gives +3.6 / +5.5 dB. The fix changes the image, so it is **Idle's call**.
- **K2:** the 1-pole corner is fc = Wet/d = 133 Hz at 3 m.
  - With air_lp 0.25 it acts as a −2.5 dB broadband step for images beyond about 3 m.
  - The code matches the Structure note, but the note's distance unit is unknown. **Needs Idle listening.**
- **K3:** the default room has 12 (C) / 20 (L, R) unique FDN delays of 32.
  - The cause is the doubly symmetric geometry. sx 2.6 + sy 1.2 gives 29/29/29, which matches Structure.
  - Changing the default geometry is **Idle's call**.
- **K4:** early reflections are 0 by default on both server and client (−17.8 dB of the first 80 ms when on).
  - Side note: a stale early lane replays when the early fader is re-enabled during playback (code read, ASSUMED audible).
