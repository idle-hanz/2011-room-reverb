# 2011 Room Reverb

Rebuild of Idle Hanz’s 2011 Reaktor room reverb: image-source early field + unscaled Hadamard FDN, mic model, Desktop FastAPI tweak app.

Live: https://idlehanz.com/tools/room-reverb/

## Quick start
1. Clone this repo
2. Open `software/` → double-click `Launch Tweak App.bat`
3. Browser → http://127.0.0.1:7860
